## The rule that matters most
**Keep the GitHub Project board in sync with the repo.** Work is tracked on **GitHub Project #8 —
"The Corrupted Virtues"** (https://github.com/users/TheSchlote/projects/8), the source of truth
for what the game does and will do. When you start work, set the item's Status to `In Progress`;
when you ship it (merge to `main` / tag), set it `Done` and close the issue; new, untracked work
gets a fresh issue added to the project (with a Status and a Phase). `ROADMAP.md` and `docs/` are
reference only — the board is the live tracker. Commands and conventions are in CLAUDE.md.
